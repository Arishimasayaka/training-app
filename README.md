# 🏋️ 50to60 Project - トレーニング＆コンディショニング管理アプリ

50代から60代にかけて「動ける魅せる身体」をつくるための、パーソナル管理ウェブアプリ（PWA対応）です。  
1年後の**10kmマラソン完走**を目指しつつ、胸・腕の立体感を最優先で強化し、ボクシングやサウナ・ジャグジーでのリカバリーまでを一元管理します。

---

## 🌟 主な機能・特徴

### 1. 🏋️ 曜日別トレーニング管理
* **週間スマートメニュー**:
  * **月曜**: 胸・二の腕集中（バーベルベンチプレス、インクラインプレス等）
  * **火曜**: 背中・三の腕（デッドリフト、ラットプルダウン等）
  * **水曜**: ボクシングレッスン（休養・調整）
  * **木曜**: 肩・パンチ力強化（ケーブルフライ、ショルダープレス等）
  * **金曜**: フル休養日
  * **土曜**: 全身・胸・マラソン脚力土台（スクワット、ベンチプレス等）
  * **日曜**: 背中・脚・二の腕調整日
* **自動重量記憶**: 過去に完了した最新の重量（kg）を自動記憶し、次回以降の初期値として自動セット。
* **回数選択の最適化**: 1回単位（9回・10回・11回など）で自在に調整可能。
* **長押しイージーカウント**: 「＋」「ー」ボタンを押し続けると、ゆったりとしたピクト（0.8秒待機・0.25秒間隔）で連続変化。
* **同部位自動チェンジ**: `🔄 種目を変更` ボタン1タップで、同じ狙い部位の代替種目へ自動ランダム交代（YouTube Shorts動画＆解説も自動連動）。
* **重量表記の明確化注記**:
  * バーベル: **「※バー（シャフト）自体の重さ（20kg等）も含めた合計重量」**
  * ダンベル: **「※ダンベル1本（片手分）の重量」**

---

### 2. 🧘 朝夜コンディショニング＆柔軟
* **🌅 朝コンディショニング（5分）**: マインドフルネス瞑想 ＋ 朝の全身ストレッチ（タイマー＆音声案内）。
* **🧘 夕方ストレッチ（5分）**: 前屈・もも裏（ハムストリングス）を重点的にほぐす5ステップ（YouTube Shorts動画連動）。

---

### 3. ♨️ リカバリー（サウナ・ジャグジー）＆ 🥤 プロテイン管理
* **サウナ＆ジャグジー記録**:
  * ジャグジーは**1単位＝8分**に最適化（8分、16分、温冷交互浴などのワンタップ記録）。
  * 温冷交互浴の推奨時間ガイドグラフを搭載。
* **プロテイン記録**: 1日あたりの目標摂取量（体重×1.2〜1.5g）に合わせたワンタップ（25g）記録機能。
* **モチベーション＆健康豆知識**: 画面上部にサウナ・ジャグジーの疲労回復メカニズムや名言がランダム表示。

---

### 4. 📊 成長グラフ＆CSVデータダウンロード
* **種目別成長グラフ**: 重量（kg）と合計回数の伸びを二軸折れ線グラフで視覚化。
* **プロテイン推移グラフ**: 日別のタンパク質摂取量を棒グラフ表示。
* **📥 CSVダウンロード**: 筋トレ・プロテイン・サウナ/ジャグジーの全履歴を文字化け防止BOM付きCSVで保存。**Microsoft Excel** や **Google スプレッドシート** でそのまま管理・分析可能。

## 📱 PWA（ホーム画面への追加方法）

1. スマホの **Safari（iOS）** または **Chrome（Android）** でアプリURLを開きます。
2. 共有メニュー（または設定メニュー）から **「ホーム画面に追加」** を選択します。
3. アプリのようなフルスクリーン表示で快適にご利用いただけます。
