# 筋トレアプリ

50代男性の健康維持・体力向上・引き締まった体作りをサポートするためのスマートフォン向け筋トレ管理アプリ（PWA）です。

## 主な機能

- **自動曜日判別機能**: 端末のローカル時間から現在の曜日を自動判定し、その日のメニューを表示します。
  - 月曜日：胸
  - 火曜日：背中（トレーニング後：ジャグジー・サウナ 20分）
  - 水曜日：ボクシングレッスン（※筋トレなし）
  - 木曜日：肩・肩幅（※ケーブルフライ必須 / 朝：サウナ）
  - 金曜日：休養日（※筋トレなし）
  - 土曜日：全身
  - 日曜日：弱点部位
- **種目・セット管理**: 1日6種目（10回×3セット、インターバル60秒）。重量は0.5kg単位で調整可能。
- **自動並び替え**: 完了した種目は自動的に「完了済み」セクションへ移動します。
- **種目変更機能**: 「変更」ボタンから別種目へ変更可能（変更後は未完了にリセット）。
- **有酸素運動＆ストレッチ機能**: 筋トレ後の20分間有酸素運動タイマーと、5分間のデイリーストレッチタイマーを搭載。
- **データ自動保存**: `localStorage` を使用し、ブラウザをリロードしても記録が保持されます。

## 使い方・ホーム画面への追加（PWA）

1. 発行された GitHub Pages の URL にスマートフォンのブラウザでアクセスします。
2. ブラウザのメニューから「ホーム画面に追加」または「アプリをインストール」を選択します。
3. ホーム画面に作成されたアイコンからいつでも全画面で起動できます。

## 技術スタック

- HTML5 / CSS3 / JavaScript (ES6+)
- Web App Manifest (PWA対応)
- GitHub Pages (静的ホスティング)
